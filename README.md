# StrawVerse Extensions 2

An extension repository for [StrawVerse](https://github.com/TheYogMehta/StrawVerse).

## 📦 Available Extensions

### Anime (2)
| Extension | Version | Description |
|-----------|---------|-------------|
| animesalt | 1.0.3 | Regional multi-language dubbed anime streaming |
| reanime | 1.0.1 | High-definition anime streaming with subbed/dubbed multi-server playback from Re:ANIME |

### Movies & TV Shows (5)
| Extension | Version | Description |
|-----------|---------|-------------|
| bingr | 1.0.0 | Multi-mirror movies, TV shows, and series streaming across Bingr domains |
| cinejoy | 1.0.8 | Movies and TV shows streaming with multiple servers and subtitles |
| dramacool | 1.0.5 | Asian dramas, Kdramas, and movies streaming |
| hdhub4u | 1.0.4 | Bollywood, Hollywood, and web series in Hindi Dubbed and Dual Audio |
| kaidrama | 1.0.2 | Korean, Chinese, and Asian dramas and movies with English subtitles |

### Manga (0)
No manga scrapers available yet. Contributions welcome!

## 🔧 Installation

1. Open **StrawVerse** → **Settings** → **Extensions**
2. Add this repository URL: `https://github.com/cyber-winner/strawverse-extentions-2`
3. Browse the Marketplace and install extensions
